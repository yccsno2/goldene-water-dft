# 原理

## 1. 量子力學基礎與密度泛函理論（DFT）

第一原理計算（First-principles calculations）不依賴任何經驗參數，直接從量子力學基本定律出發求解多電子系統的電子結構與基態性質，其核心為非相對論定態薛丁格方程式：

$$H\Psi = E\Psi$$

其中 $H$ 為系統的哈密頓算符（Hamiltonian），$\Psi$ 為多體波函數，$E$ 為系統總能量。針對包含大量原子與電子的實際材料系統，本專題採用**密度泛函理論（Density Functional Theory, DFT）**，透過 **Kohn-Sham 方程式**將複雜的多電子交互作用問題映射為等效的單電子在有效位勢中運動的問題，藉由電子密度 $\rho(\mathbf{r})$ 精確求解系統基態能量與電子分佈。

---

## 2. 原子受力與結構最佳化（Hellmann-Feynman 定理）

在幾何結構最佳化（Geometry Optimization）與分子動力學模擬中，必須精確計算每個原子核所受的合力。根據 **Hellmann-Feynman 定理**，原子核在位置 $\mathbf{R}$ 所受的量子力學作用力可由基態波函數與哈密頓算符對原子座標的偏微分求得：

$$\mathbf{F} = -\left\langle \Psi \left| \frac{\partial H}{\partial \mathbf{R}} \right| \Psi \right\rangle$$

在 VASP 計算中，系統會反覆進行自洽場（SCF）電子步收斂以獲得精確電子密度，再依據上述原子受力推動離子移動，直到所有原子的最大殘餘受力低於收斂標準（`EDIFFG = -0.01` eV/Å），藉此找出水分子於金烯表面的穩定吸附構型。

---

## 3. 交換關聯泛函與凡得瓦力修正

為精確描述二維單原子層金（Goldene）之電子結構與表面吸附行為，本專題採用以下理論近似：

* **交換關聯泛函（GGA-PBE）**：採用廣義梯度近似（Generalized Gradient Approximation）中的 PBE 泛函，同時考量電子密度及其梯度變化，能準確描述金屬表面與吸附分子間的共價與極性交互作用。
* **色散力修正（DFT-D3）**：傳統 DFT 泛函難以完整捕捉長程凡得瓦力（van der Waals interaction）。本專題引入 Grimme 提出的 **DFT-D3** 色散修正（`IVDW = 11`），透過原子對之間的色散能量項補強極性水分子（$\text{H}_2\text{O}$）與二維金屬表面之間的弱交互作用，避免低估物理吸附強度。

## 4. 吸附能熱力學定義

為量化水分子與解離物種（$\text{OH}$、$\text{H}$）在金烯不同高對稱位點（Top、Bridge、Hollow）的結合穩定度，吸附能 $E_{\text{ads}}$ 定義為：

$$E_{\text{ads}} = E_{\text{slab+mol}} - E_{\text{slab}} - E_{\text{mol}}$$

* $E_{\text{slab+mol}}$：吸附物種與金烯基底形成複合系統並完成結構弛豫後之總能量
* $E_{\text{slab}}$：潔淨 36 原子單層金烯基底之總能量
* $E_{\text{mol}}$：氣相孤立分子之總能量

當計算所得之 $E_{\text{ads}} < 0$ 時，表示該吸附過程為放熱反應，且負值越大代表吸附構型在熱力學上越穩定。

## 5. 計算材料科學之多尺度模擬定位

在現代計算材料科學中，不同理論模擬方法在**計算精確度（Accuracy）**與**計算效率（Efficiency）**之間各有定位：

| 模擬方法 | 核心方程式 / 數學架構 | 特性與適用尺度 |
| :--- | :--- | :--- |
| **第一原理計算（DFT）** | $H\Psi = E\Psi$，$\mathbf{F} = -\langle\Psi|\frac{\partial H}{\partial \mathbf{R}}|\Psi\rangle$ | **精確度最高**，可解析電子轉移、軌域混成與化學鍵斷裂/生成，適合研究催化反應機制 |
| **機器學習勢能（MLP）** | $U(\mathbf{X}) = \sum_{i_B} w_{i_B} K(\mathbf{X}, \mathbf{X}_{i_B})$ | 透過結構描述符 $\mathbf{X}$ 擬合 DFT 位能面，兼顧接近第一原理的準確度與大尺度模擬效率 |
| **古典分子動力學（MD）** | $\mathbf{F} = -\nabla U = m\mathbf{a}$ | **計算效率最高**，適合模擬數萬至數百萬原子之長時間熱力學演化與傳輸性質 |

由於本專題的核心目標在於探討水分子於二維金烯表面的**電子結構交互作用、精確吸附能排序以及水分子解離催化機制**，因此採用具備最高量子力學精確度的**第一原理 DFT 方法**進行研究。
