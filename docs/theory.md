# 原理

## 密度泛函理論（DFT）
本專題採用基於 Kohn-Sham 方程式之第一原理密度泛函理論，透過電子密度求解多體系統之基態能量與電子結構。

## 交換關聯泛函與凡得瓦力修正
採用廣義梯度近似 **GGA-PBE** 描述交換關聯能，並引入 Grimme **DFT-D3** 色散修正（`IVDW = 11`），以準確捕捉極性水分子與二維金屬表面之間的弱凡得瓦交互作用。

## 吸附能定義
水分子於金烯表面之吸附能 $E_{\text{ads}}$ 定義如下：

$$E_{\text{ads}} = E_{\text{slab+mol}} - E_{\text{slab}} - E_{\text{mol}}$$

* $E_{\text{slab+mol}}$：吸附系統之總能量
* $E_{\text{slab}}$：潔淨金烯基底之總能量
* $E_{\text{mol}}$：氣相孤立分子之總能量
