# 實驗設定

## 計算模型設定
* **基底超晶胞**：36 原子單層金烯（$6 \times 3 \times 1$）
* **真空層厚度**：沿 $z$ 軸方向保留充足真空層，消除週期性邊界條件造成的層間交互作用。

## VASP 核心參數（INCAR）

| 參數名稱 | 設定值 | 說明 |
| :--- | :--- | :--- |
| **泛函** | PAW-PBE | 投影綴加波贗勢與 PBE 泛函 |
| **色散修正** | `IVDW = 11` | DFT-D3 無阻尼凡得瓦修正 |
| **截斷能** | `ENCUT = 400` eV | 平面波基底截斷能 |
| **電子收斂標準** | `EDIFF = 1E-6` eV | SCF 能量收斂閾值 |
| **離子收斂標準** | `EDIFFG = -0.01` eV/Å | 原子最大殘餘受力閾值 |
| **展寬設定** | `ISMEAR = 0`, `SIGMA = 0.05` | 高斯展寬（Gaussian smearing） |
| **最佳化演算法** | `IBRION = 2`, `POTIM = 0.1` | 共軛梯度法（CG） |
| **偶極修正** | `LDIPOL = .TRUE.` | 平板設 `IDIPOL = 3`；孤立分子設 `IDIPOL = 4` |
